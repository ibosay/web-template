# Quiz Mobile App

The quiz is prepared as a Capacitor app for iOS and Android.

## Current app experience

- Mobile-first quiz UI
- Categories, timer, scoring and streak bonuses
- Persistent high scores
- Persistent XP, level, rounds played, correct answers and best streak
- Dedicated native presentation without marketplace navigation or footer
- iPhone safe-area support
- Dark splash-screen configuration
- Local quiz questions, so gameplay itself does not require a question API

## First native setup

1. Run `yarn install`.
2. Run `yarn build-web`.
3. Run `yarn app:add:ios` on macOS for the iOS project.
4. Run `yarn app:add:android` for the Android project.
5. Run `yarn app:sync`.

After the native projects exist, use `yarn app:prepare` after web changes.

Open Xcode with `yarn app:ios` or Android Studio with `yarn app:android`.
For a connected simulator/device, `yarn app:run:ios` and `yarn app:run:android` are also available.

## Release checklist

Before calling a store build finished:

1. Generate the native `ios/` and `android/` projects.
2. Build the web bundle and run Capacitor sync.
3. Run the quiz test suite and a production build.
4. Test a complete round on a real iPhone and Android device.
5. Verify rotation, safe areas, keyboard behavior and app resume.
6. Add final app icon and splash assets.
7. Set signing, bundle identifiers, version/build numbers and store metadata.
8. Produce signed App Store and Play Store builds.

The native directories are generated by Capacitor and are not claimed to exist until the add commands have actually been executed.


## Native splash screen

The app uses Capacitor's official `@capacitor/splash-screen` plugin. After installing dependencies,
run `yarn app:prepare` so the plugin is synchronized into the generated iOS and Android projects.
The current splash background is `#080D1C`, the spinner is disabled, and the launch duration is
1200 ms. Final branded splash artwork still needs to be added before store release.
