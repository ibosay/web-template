# Friseurplan v2

Diese Branch dokumentiert die überarbeitete Friseurplan Version.

## Bereits umgesetzt

• kompaktere mobile Oberfläche mit einklappbaren Filtern
• Sortierung nach Nähe oder Bewertung
• zunächst 24 Einträge, danach schrittweises Nachladen
• deutlich ruhigere Salon Karten
• direkter Termin Anfrage Button
• Pflichtfeld Prüfung bei Terminwünschen
• bessere Hinweise, Metadaten und Barrierefreiheit
• weiterhin Suche, Bezirke, Standort, Favoriten, Karte, Preise, Öffnungszeiten und lokaler Adminbereich

## Nächster technischer Schritt

Die bisherige Einzeldatei ist ein funktionsfähiger Prototyp. Für echte verbindliche Buchungen, zentrale Statistiken, Salon Logins und salonübergreifende Datenpflege wird eine Web App mit Datenbank und Rollenmodell benötigt. Die Replit Fassung soll diese produktive Architektur übernehmen.
